How it is drawn

Speed test

Each test draws one frame 45 times (the first five only get the mode ready) and waits for the graphics chip every time, then plays the video for a few seconds and counts the frames it kept up with. "Smooth" leaves room to spare; "tight" keeps up, barely; "too slow" misses frames.
